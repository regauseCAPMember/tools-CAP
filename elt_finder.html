Math Notes / Field Caveats

Circumcenter points create perpendicular bisectors of chords. Directional and Wing Null points create rays from known positions. The estimator uses all available lines; it only uses a two-circumcenter perpendicular when other directional lines can select the practical crossing side. Long-distance accuracy is approximated with a local tangent plane centered on the input points, which is appropriate for SAR-scale work but not geodetic survey work.

Devil's-advocate checks included: near-parallel lines, duplicate points, bad bearings, left/right wing normalization, RMS fit error, and geometry quality warnings.
